Welcome to the official source code of my personal engineering portfolio. Designed with inspiration from the award-winning **igloo.inc** aesthetic, featuring procedural 3D crystalline WebGL graphics, frosted glassmorphism, kinetic typography, and a live client-side machine learning simulator.

## 💎 Design & Architecture (Learned from igloo.inc)
- **Three.js 3D Crystalline Core**: Interactive, double-layered polyhedral ice crystal with wireframe glass lattice and refractive glowing vertices that users can click and drag to tumble in 3D space.
- **Kinetic Text Decryption**: High-tech character scramble / matrix solver effect on headings and interactive elements.
- **Interactive Cosmic Particle Footer**: Particle vortex in the footer responding dynamically to mouse movement and velocity.
- **Synthesized Web Audio API FX**: Discrete, futuristic UI audio feedback for clicks, toggles, and modal launches with a one-click mute toggle.
- **Live Interactive ML Classifier Playground**: Client-side Fisher Iris vector classifier simulator with interactive sliders, dynamic probability curves, and confidence telemetry.
- **Crystalline Bento Grid**: Showcases production projects (Apex Downloader with WASM FFmpeg, Epic Games Auto Claimer bot, Whisper-Pulse, MNIST SVM, etc.) encased in frosted crystalline slabs.
- **Laser Spine Roadmap**: Illuminated vertical timeline tracing academic and career milestones.
- **Command Palette (`Ctrl + K` / `Cmd + K`)**: Frosted glass search HUD with keyboard navigation.
- **Instant Dual Theme**: Crystalline Dark & Arctic Frost Light mode with persistent state.

## 🔧 Setup & Run Locally
1. **Clone the repository**
   ```bash
   git clone https://github.com/amit-649/My-Portfolio.git
   cd My-Portfolio
   ```

2. **Launch Locally**
   Open `index.html` in your browser, or launch using VS Code Live Server / `npx serve .`.

3. **Optional Configuration (`js/config.js`)**
   - Configure a free [Web3Forms](https://web3forms.com/) key in `js/config.js` to enable direct contact form submissions.
